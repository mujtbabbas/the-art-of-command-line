# Reader's Guide — the-art-of-command-line

## What this project is

**The Art of Command Line** is a one-page distillation of **what to know
about the command line** — the essentials that are usually scattered across
years of experience: shell fluency, file and data processing, system
debugging, and the obscure commands that save the day once a year. It aims at
broad coverage over depth: skim it in an hour, use it as a reference forever.

## How the content is organised

The whole guide is [`README.md`](README.md), in one flowing sequence:

- **Meta** — scope, audience and how much time to spend.
- **Basics** — the core shell concepts and commands to learn first.
- **Everyday use** — keyboard shortcuts, history tricks, and the daily
  workflow upgrades.
- **Processing files and data** — working with text and files as data:
  finding, transforming, summarising.
- **System debugging** — inspecting processes, networks, disks when
  something is wrong.
- **One-liners** — short composed commands that do real jobs.
- **Obscure but useful** — commands you will rarely need and be glad to know.
- **macOS only** and **Windows only** — platform-specific sections (the
  Windows part covers getting Unix tools under Windows, useful native tools,
  and Cygwin tips).
- **More resources**, **Disclaimer**, **License** (CC BY-SA 4.0).

The guide is translated into **17 more languages**, each a full
`README-<lang>.md` beside the English original (Čeština, Deutsch, Ελληνικά,
Español, Français, Indonesia, Italiano, 日本語， 한국어, polski, Português,
Română, Русский, Slovenščina, Українська, 简体中文， 繁體中文）.
`AUTHORS.md` credits the many contributors; `admin/` holds project
administration notes.

## How to use it

1. Read **Meta** and **Basics** straight through once.
2. Skim the rest, bookmarking the commands you did not know — the
   **One-liners** and **System debugging** sections repay revisits.
3. Keep it as a reference: when a shell task feels clumsy, search the page —
   there is usually a two-command answer.
